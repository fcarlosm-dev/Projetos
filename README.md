# Projeto
Calculadora de consumo de energia 
Linguagem: Phyton
Fórmula de cálculo:consumoMensal = (potencia * horasDia * 30) / 1000
Instruções de uso:
Informar o nome do aparelho ex.: Geladeira
Informar a potência do aparelho em watts (W) 110/220
Informar o tempo médio de uso diário em horas
Informar o valor do kWh em R$ - ex.: 1.0825

# Objetivo
Projeto criado com o intiuito de que o consumidor/cliente possa calcular o impacto de consumo energético que cada equipamento em sua residência/comércio pode gerar.
A ideia é que após o cálculo, o consumidor/cliente tenha a dimensão do gasto e possa tomar atitudes mais conscientes de economia.
Projeto aberto para adicionar novas funcionalidades.
